Para el correo: la G animada (GIF) debe estar subida a una URL (ej. https://asesoria-financiera.vercel.app/firma/g.gif), porque Gmail no acepta imágenes incrustadas. En el HTML que copias, El GIF es el mismo para todas las marcas: GlobalWealth-G-animada.gif.
Instalar: Gmail → Configuración → Firma → pega. Outlook/Apple Mail → sección de firma.
